# Do Not Ship

Hard guardrails. Violations block merge.

- Fake confidence / fake progress / fake success
- Unexplained personalization
- Disruptive AI or auto-edit without approval
- Animations that compete with code
- Technical jargon as *primary* explanation (jargon in detail is fine)
- Silent data collection
- Stale preview presented as current
- Friendly language that obscures serious failures
- Auto-fix, auto-suppress, auto-ignore, auto-rewrite without user approval
- Another way to do the same thing (see Navigation Contract)
- Feature that requires configuration to work at all
